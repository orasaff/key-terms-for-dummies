# key-terms-for-dummies
Web extension for collecting unknown words/phrase simply by dragging. This program creates a vocabulary list with definitions and provides replacement with elementary school-level alternative words on the screen.

Inspired by the book "Munhae naegong [The inner strength of literacy]" and its idea that unfamiliar key concepts takes up big cognitive load, whereas skilled readers that have background knowledge of these vocabularies are able using chuncking mechanism and more quickly comprehend the structure and the big picture of the writing.

Reference
Shin, J. H., & Kim, Y. J. (2026). Munhae naegong [The inner strength of literacy]. Sangsang Square.
